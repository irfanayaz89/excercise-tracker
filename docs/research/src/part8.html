Appendix. Glossary

MVPMinimum viable product: the smallest release that keeps the product's promise (section 4).
ShieldApple's system screen shown in place of a blocked app or site. Text and buttons can be customised.
TokenAn anonymous iOS identifier for a picked app, category or website. The app can block with it, but can't read which app it is.
ExtensionA small separate program inside the app bundle that iOS runs on its own (monitor, shield configuration, shield action).
Individual / child authorizationAn adult managing their own phone, or a parent approving an app for a child in Family Sharing.
EntitlementA capability Apple must grant an app (here Family Controls) before it can use certain APIs.
Usage accessThe Android setting that lets an app read which apps were used, and when.
Foreground serviceAn Android background task with a visible notification, which Android keeps alive.
HeartbeatA timestamp the Android service saves every few seconds; a gap shows the service wasn't running.
