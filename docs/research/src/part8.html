Appendix. Glossary

MVPMinimum viable product: the smallest release that keeps the product's promise (section 4).
ShieldApple's system screen shown in place of a blocked app or site; its text and buttons can be customised.
TokenAn anonymous iOS identifier for a picked app, category or website; the app can block with it but can't read which app it is.
StoreA named ManagedSettingsStore holding one set of iOS restrictions; the most restrictive store wins.
ExtensionA small program in the app bundle that iOS runs on its own (monitor, shield configuration, shield action).
Individual / child authorizationAn adult managing their own phone, or a parent approving an app for a child in Family Sharing.
EntitlementA capability Apple must grant (here Family Controls) before an app can use certain APIs.
Usage accessThe Android setting that lets an app read which apps were used, and when.
HeartbeatA timestamp the Android service saves every few seconds; a gap shows it wasn't running.
