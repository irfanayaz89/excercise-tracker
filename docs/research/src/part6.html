10Technical architecture

The structure below suits any cross-platform or fully native app: one rules engine decides, and thin native code on each platform applies the decision.

10.2 Architecture diagram

Why the rules live in one shared engine: one implementation serves both platforms and can be unit-tested across time zones and daylight-saving changes; native code stays a small mirror of "what's blocked right now"; and app lists travel inside the plan, so changing them follows the same strictness rules as any other change.

Expo and React Native notes: Expo Go can't run this, so a development build is required. The iOS extensions are generated from config (@bacons/apple-targets), never by hand-editing ios/. Add the entitlement and extensions behind a build flag, so builds from free Apple teams keep working. An iOS-only library, react-native-device-activity, covers similar ground [113]; Foqos is an open-source native example [114]. Extensions must stay tiny: no JavaScript runtime, database or network.

10.3 Safe removal and interrupted sessions

  1. No block without an end. Every focus, unlock and lock-time edge is registered with the system.
  2. A hard cap on focus length (3 h), so a bad input can't lock someone out for a day.
  3. Reconcile on every app open: recompute from the rules and clock, clear anything expired, re-register schedules. This also repairs schedules lost after a reboot [29].
  4. An emergency path sized by strictness (section 4, M8), and an always-allowed list.
  5. An explicit "Turn off" that clears every store before the user deletes the app, because what happens to shields after deletion is undocumented [30].
  6. Protection lost: record the gap in history, show a red banner, and offer to re-grant.

11User experience: honest wording

The feature should feel like a tool the user chose, not parental monitoring: a short setup (M1), a fair way out (M8), and wording that doesn't overpromise.

Suggested wording: "This blocks the apps you choose and makes switching it off take effort. You can always remove Screen Time access in Settings or delete the app; if you do, it will show in your history."

Never promise:

  • "Can't be bypassed", "uninstall-proof" or "impossible to turn off": false for adults on both platforms.
  • "Exact screen time" on iPhone: it's coarse, and sometimes wrong.
  • "Blocks every app": 50 apps per list on iOS, and up to about a second of delay on Android.
  • "Works the same on every Android phone": battery savers vary by maker.
