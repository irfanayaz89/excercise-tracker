6Android in depth

Android has no public API to block other apps and no third-party hook into Digital Wellbeing timers. Android 16 QPR2 (December 2025, Pixel first) added Parental Controls in Settings, with no developer API [65]. Every consumer blocker combines general-purpose permissions.

6.2 How the once-a-second check works

  • App in front: each second, read the new usage events [35] and keep activities that resumed and haven't paused; the newest is in front. "The last app that resumed" fails, because the home screen can resume and pause in the same instant. After a restart, look back a few hours.
  • Counting: keep unsaved seconds in memory and add them back whenever saved state is re-read; save every 10 s and when what's blocked changes. Skip work while the screen is off, and run the loop off the main thread.
  • Categories are only partial: many apps declare none, so the app's list is per app.
