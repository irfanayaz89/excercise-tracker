6Android in depth

Android has no public API to block other apps and no third-party hook into Digital Wellbeing app timers. Android 16 QPR2 and 17 added built-in parental controls, with no developer API [34][65]. Every consumer blocker combines general-purpose permissions.

6.2 How the once-a-second check works (timing and battery)

  • Detecting the app in front: every second the service reads the last few seconds of usage events and takes the last ACTIVITY_RESUMED package [35]. There's no push callback for third-party apps [34][89], so a blocked app can be visible for up to about a second.
  • Counting usage: each second in a blocked app adds to today's total. State is saved every 10 s and whenever what's blocked changes.
  • Battery and stability: skip work while the screen is off, throttle re-opening the block screen, and run the loop on a background thread, not the main thread.
